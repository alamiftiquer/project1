# Photography Sidebar Menu Project

This project is a CSS-based sidebar menu designed for a photography website. It features a slide-out navigation panel built entirely without JavaScript.


<img width="1920" height="871" alt="image" src="https://github.com/user-attachments/assets/f3e4da95-d627-4d99-8ac3-c565bebf5040" />



## Features

* **CSS-Only Toggle:** Utilizes a hidden checkbox (`#check`) to control the opening and closing of the sidebar.


* **Sliding Animation:** The sidebar smoothly transitions from off-screen (`left: -300px`) into view when the hamburger menu icon is clicked.


* **Navigation Links:** Includes photography-themed menu options such as Gallery, Shortcuts, Exhibits, Events, Store, Contact, and Feedback, each paired with Font Awesome icons.


* **Social Media Footer:** Contains placeholder links for Facebook, Twitter, Instagram, and YouTube at the bottom of the sidebar with hover scaling effects.


* **Custom Typography:** Uses the "Poppins" font imported from Google Fonts for a clean, modern look.


* **Background Setup:** The main container is styled to display a full-screen background image (`photo.jpg`) covering the viewport.



## Files Included

* `index_2.html`: Contains the structural layout, including the checkbox toggle, hamburger menu icon, sidebar list, and external resource links.


* `style_2.css`: Contains the visual styling, hover effects, and the CSS logic to toggle the sidebar's visibility based on the checkbox's `:checked` state.



## Setup Instructions

1. Download both `index_2.html` and `style_2.css` into the same project folder.
2. Update the stylesheet link in `index_2.html`: Change `<link rel="stylesheet" href="style.css">` to point to `style_2.css`.


3. Add an image file named `photo.jpg` to the project folder to serve as the background.


4. Open the HTML file in any modern web browser to view and interact with the menu.
